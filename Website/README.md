# D.S. Design Sense LLP

The website of **D.S. Design Sense LLP**: architects, interior designers and project managers in Faridabad, established in 2001 and part of the DSW Group.

Built as the final project for the *Website Development* course (IIM Bangalore).

## Concept

The site opens with the firm's own banner: the DS mark, the plum name and tagline, and the pencil sketch behind them. Here the sketch is redrawn as 233 vector strokes that draw themselves in and keep re-sketching slowly. Below the banner, the body is calm and editorial, set in the firm's plum and greys, with one serif-italic accent word per heading.

The centrepiece is **the DS Concept House**: an original three-level home modelled in real-time 3D for this website, with furnished rooms on every floor. It is a concept, not a client's property.

## The 3D house (`js/3d/`)

- **Three.js r187**, with `RoomEnvironment` and `BufferGeometryUtils`, saved locally in `vendor/`.
- About 2,200 parts, merged into roughly 170 meshes. All textures (marble, teak, walnut, stone, lawn, pavers, water and more) are drawn on canvases in code, so the model loads no image files.
- **Controls:**
  - camera presets and a six-stop guided tour
  - time of day from 6 am to 8 pm, with night lighting
  - exploded levels, floor isolation and a section cut
  - live material swaps
  - clickable rooms with service links
  - room labels, fullscreen and a PNG snapshot
  - keyboard orbit
- Rendering pauses when the model is off screen. The home hero is a lighter version without furniture. A still image and the room list replace the model where WebGL isn't available.

## Built with

- Semantic HTML5, generated by `../build.py` from the page bodies in `../src/pages/`.
- CSS3:
  - custom properties, Grid, Flexbox and 3D transforms
  - stroke-dash animation for the banner
  - stylesheets: `css/site.css` and `css/x3d.css`
- Vanilla JavaScript (`js/site.js`):
  - IntersectionObserver
  - form validation
  - filters, lightbox, plan explorer and brief builder
- GSAP 3 with ScrollTrigger, and Lenis, all saved locally in `vendor/`.
- Google Fonts: Jost, Instrument Serif, Oswald, Open Sans and DM Mono.

Motion is reduced automatically for visitors who ask for it in their device settings.

## Editing

Edit a page body in `src/pages/`, or the project data at the top of `build.py`, then run:

```bash
python3 build.py
```

The build also checks every link, anchor and image, and fails if a removed name or number reappears.

## Enquiries

GitHub Pages only serves static files, so the brief builder opens a ready-written email to info@designsense.co.in. To receive briefs without the visitor's email app, create a form at [formspree.io](https://formspree.io) and add its ID in `js/site.js`:

```js
const SITE = { email: "info@designsense.co.in", phone: "+91 129 419 9722", formspreeId: "your-form-id" };
```

## Run locally

```bash
python3 -m http.server 5600
```

Then open <http://localhost:5600>. The 3D model needs a web server; it won't load from `file://`.
